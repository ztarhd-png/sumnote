설정 및 도움말

숨노트의 데이터는 이 기기의 현재 브라우저 저장소에 남습니다. 브라우저 데이터를 지우면 사라지니, 중요한 노트는 JSON으로 백업하거나 GitHub 동기화를 켜 두세요.

다른 기기와 맞추기

본인 GitHub의 비공개 저장소에 노트를 두면 아이폰과 PC에서 같은 노트를 보고 고칠 수 있어요.

자유롭게 쓰는 계산

  • 새 노트는 바로 열려요. 첫 줄이 제목이 되고, 첫 줄은 합계에 넣지 않아요.
  • 점심 12,000 → 12,000
  • 국세 24,990 지방세 2,490 → 27,480 (한 줄의 금액은 모두 더해요)
  • 6억, 12,000원, 마운트타입4, P5B3-KR처럼 숫자 앞이나 뒤에 글자가 붙으면 표기로 보고 계산하지 않아요. 금액은 띄어 쓰세요. 합계에 들어간 숫자는 본문에서 파랑(더하기)·빨강(빼기) 형광펜으로 표시돼요. 쓰는 동안은 보통 메모장처럼 쓰고, 위쪽 저장을 누르면 색과 합계가 맞춰져요.
  • 2013~2014, 3 ~ 5처럼 물결(~) 양쪽 숫자는 범위로 보고 계산하지 않아요.
  • -5000, −5000은 차감합니다. 사칙연산은 하지 않아요: 5000-3000, 12000*3처럼 기호로 붙여 쓰면 글로 보고, 5000 -3000처럼 띄우면 숫자 두 개(5000과 -3000)로 더해요.
  • # 또는 //로 시작하는 줄은 제외합니다.

AI 정리

위쪽 AI를 누르고 말로 시키면 줄을 정렬하고, 거르고, 다른 노트나 폴더로 옮겨 줍니다. 날짜를 앞으로 옮기는 것처럼 줄의 형식을 바꾸거나 문단으로 나누는 일도 됩니다. 앱이 금액을 하나씩 대조하고 전체 합계까지 맞춰 보며, 하나라도 다르면 적용하지 않아요. 적용하기 전에 결과를 먼저 보여 주고, 적용한 뒤에도 최근 10번까지 되돌릴 수 있어요. 본인의 Claude API 키가 필요하며, 실행할 때 지금 노트의 내용과 다른 노트의 제목, 폴더 이름이 Anthropic으로 전송됩니다.

검색

메뉴의 검색칸에 적으면 바로 단순 검색을 해요. 낱말이 모두 들어 있는 줄을 노트마다 보여 주고, 줄을 누르면 그 노트의 그 줄로 갑니다. 대소문자와 숫자의 쉼표는 가리지 않아요(12000으로 12,000도 찾아요).

AI 검색은 낱말이 정확하지 않아도 뜻으로 찾아요. ‘신발’로 로퍼와 스니커를, ‘10만원 넘는 옷’처럼 조건으로도 찾습니다. 누를 때마다 비용이 들고, 모든 노트의 내용이 Anthropic으로 전송됩니다.

홈 화면 앱과 업데이트

아이폰 Safari의 공유 버튼에서 ‘홈 화면에 추가’를 선택하세요. 새 버전이 나오면 화면 위쪽에 작은 업데이트 버튼이 보입니다. 누를 때만 새 버전으로 바뀌고, 노트는 그대로 남아요. 앱을 다시 추가할 필요가 없습니다.

홈 화면에서 앱을 지우면 그 안의 노트도 함께 지워집니다. 지워야 할 때는 먼저 ‘전체 JSON 백업’으로 ‘파일’에 저장하고, 다시 추가한 뒤 ‘JSON 가져오기’로 불러오세요.

가져온 노트와 폴더는 기존 데이터에 추가됩니다. CSV는 현재 노트의 원문과 계산값을 담습니다.
